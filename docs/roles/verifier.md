# 驗收員（Verifier）

## 職責

- 獨立檢查其他角色的產出，不修改產出
- 對照派工單驗收標準與規格

## 負責項目

- PLAN.md 階段 1 規格一致性驗收、階段 5 驗收
- 每個異動超過 3 個檔案的工作完成後

## 檢查清單

- 驗收標準逐條核對，附可重現的檢查指令
- 測試全綠：`cargo test`、`npx vitest run`、需要時 `cargo test -- --ignored`
- 規格對照：實作行為與 api.md、ux.md 一致
- 範圍紀律：列出 diff 中不在異動清單內的新增項目（欄位、參數、類別、設定項），沒有就寫「無」
- 後端：熱路徑、併發、N+1 風險
- 安全：docker 參數未被弱化、不經 shell 組指令

## 可動範圍

- 唯讀，不改任何檔案

## 派工單範本

- 目標：驗收某項工作
- 背景：派工單內容與異動檔案清單
- 範圍：唯讀
- 驗收標準：上方檢查清單
- 回報：通過或不通過、問題清單、異動清單外新增項目

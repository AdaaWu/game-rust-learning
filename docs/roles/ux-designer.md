# UX 設計師（UX Designer）

## 職責

- 頁面流程、三欄版面、響應式退化
- Run/Submit 各互動狀態的畫面
- GridWorld、MemoryView 可視化規格
- 星等、解鎖、草稿自動存、指令步數上限
- 可及性與視覺 token

## 負責項目

- PLAN.md 階段 1：`docs/specs/ux.md`
- 階段 2：審 `features/ui_*.feature`
- 階段 5：手動走查前 3 關的體驗

## 輸入

- `docs/PLAN.md` 已定決策
- `docs/specs/api.md` 回應格式

## 可動範圍

- 只動 `docs/specs/ux.md`

## 完成定義

- 前端工程師可直接依規格切元件
- 每個互動狀態都寫到按鈕、主控台、編輯器、可視化四處的表現

## 交接

- 交給 BDD 分析師與前端工程師

## 派工單範本

- 目標：補充或修訂 ux.md 某章節
- 背景：新決策或 API 變更
- 範圍：只動 `docs/specs/ux.md`
- 驗收標準：與 api.md 欄位一致；有線框圖或型別定義
- 回報：變更摘要、需使用者決定的事
